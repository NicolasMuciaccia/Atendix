Text button for actions; navy `primary` for the one main CTA per view, `secondary` for suggestions and neutral actions.

```jsx
<Button iconLeft="plus">Novo ticket</Button>
<Button size="sm" iconRight="arrow-right">Enviar</Button>
<Button variant="secondary" size="sm">Verificar status da conta</Button>
```

- `accent` (blue) for marketing/onboarding CTAs; in-app primaries stay navy.
- Press = scale(.98). Disabled = 45% opacity.
