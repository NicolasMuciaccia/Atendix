Message bubble in a ticket thread — customer, agent or internal note.

```jsx
<Message author="Priya Sharma" time="10:24" role="customer"><p>Oi, equipe…</p></Message>
```

- Customer: gray #F4F6FA; agent: blue-tinted #EEF3FF; note: amber with lock label.
- Child `<p>` margins are up to you — use `margin: 0 0 8px`.
